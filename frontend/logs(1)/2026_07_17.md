# 2026년 7월 17일 프론트엔드 작업

## 1. 작업 목적

기존 Python 콘솔 프로그램의 계산 결과를 웹 UI로 확인할 수 있도록
React 기반 프론트엔드를 시작한다.

현재 카페에서는 업비트 API 인증 IP가 달라 백엔드 테스트가 어려우므로,
가짜 데이터를 사용해 UI 구조와 화면 이동을 먼저 구현한다.

---

## 2. 프로젝트 핵심 목적

업비트에서는 여러 매수 거래가 평균 매수가로 합쳐져 표시되기 때문에
개별 매수 거래별 수익률을 확인하기 어렵다.

이 프로젝트에서는 다음 기능을 제공한다.

- 현재 보유 중인 코인 확인
- 코인별 전체 보유 현황 확인
- 개별 매수 거래별 수익률 확인
- 매도할 개별 거래 선택
- 예상 매도가와 수량 입력
- 예상 실현손익과 수익률 확인

---

## 3. 화면 이동 구조

```text
내 보유 자산
    ↓ 코인 선택
코인별 개별 거래
    ↓ 개별 거래의 매도 계산 선택
예상 매도 계산
```

---

## 4. 초기 화면 구성

### 화면 1. 내 보유 자산

- 표시할 정보:
  - 총 매수금액
  - 총 평가금액
  - 평가손익
  - 전체 수익률
  - 현재 보유 중인 코인 목록

- 코인별 표시 정보:
  - 코인명
  - 현재가
  - 보유수량
  - 평균 매수가
  - 평가금액
  - 평가손익
  - 수익률

코인 카드를 누르면 해당 코인의 개별 거래 화면으로 이동한다.

### 화면 2. 코인별 개별 거래

- 상단 표시 정보:
  - 코인명
  - 현재가
  - 전체 보유수량
  - 평균 매수가
  - 전체 평가손익
  - 전체 수익률

- 개별 거래별 표시 정보:
  - 체결시간
  - 매수가
  - 남은 보유수량
  - 매수 원금
  - 매수 수수료
  - 실제 매수원가
  - 현재 평가금액
  - 평가손익
  - 수익률
  - 매도 계산 버튼

### 화면 3. 예상 매도 계산

- 선택한 거래 정보:
  - 매수일시
  - 매수가
  - 남은 보유수량
  - 실제 매수원가

- 사용자 입력:
  - 매도 예정가
  - 매도 예정수량
  - 전량 입력 버튼

- 예상 결과:
  - 예상 매도금액
  - 예상 매도 수수료
  - 예상 정산금액
  - 매도한 수량의 원가
  - 예상 실현손익
  - 예상 실현수익률
  - 매도 후 남은 수량
  - 매도 후 남은 원가
