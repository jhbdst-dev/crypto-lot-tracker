# 다음 작업: 선택 매도 기능

## 1. 매도 기능의 목적 정리

프로젝트에서 실제 주문을 실행하지 않는다.

프로젝트의 역할:

- 매도할 매수 거래 선택
- 매도 예정 가격 입력
- 매도 예정 수량 입력
- 예상 수수료 계산
- 예상 정산금액 계산
- 예상 실현손익 계산
- 예상 실현수익률 계산
- 실제 체결 완료 후 매도 기록 저장
- 선택한 매수 거래의 남은 수량 갱신

실제 주문의 역할:

- 업비트 앱에서 직접 지정가 매도
- 실제 체결 여부 확인

## 2. 기존 매도 계산 구조 확인

현재 `calculate_sell()`은 다음 값을 사용한다.

```python
total_quantity
total_buy_amount
sell_quantity
sell_price
fee_rate
average_buy_price
```

현재 구조는 전체 평균 매수가를 기준으로 매도 원가를 계산한다.

```python
sold_buy_amount = average_buy_price * sell_quantity
```

하지만 앞으로는 사용자가 선택한 개별 매수 거래를 기준으로 계산해야 한다.

변경 방향:

```python
sold_buy_amount = selected_buy_unit_cost * sell_quantity
```

남은 수량도 전체 보유수량이 아니라 선택한 거래의 남은 수량에서 차감해야 한다.

```python
remaining_quantity = selected_trade_remaining_quantity - sell_quantity
```

## 3. 터미널 입력 방식으로 먼저 구현

UI를 만들기 전에는 터미널 입력으로 기능을 테스트한다.

예상 흐름:

```text
보유 중인 개별 매수 거래 출력
→ 매도할 거래 ID 입력
→ 매도 예정 가격 입력
→ 매도 예정 수량 입력
→ 예상 손익 계산
→ 결과 출력
```

예시:

```text
[보유 매수 거래]

거래 ID: 4
매수가: 1,717원
남은 수량: 100개

매도할 거래 ID: 4
매도 예정 가격: 1,900
매도 예정 수량: 60
```

예상 결과:

```text
예상 매도금액
예상 매도 수수료
예상 정산금액
선택한 매수분의 원가
예상 실현손익
예상 실현수익률
매도 후 남은 수량
```

## 4. 오늘 구현할 작업

### PHASE 1: 선택 거래 찾기

- [✅] `per_trade_results`에서 거래 ID 목록 출력
- [✅] 터미널에서 `selected_trade_id` 입력
- [✅] 입력한 ID와 일치하는 거래 찾기
- [✅] 존재하지 않는 거래 ID 예외 처리
- [✅] 선택한 거래 정보 출력

필요한 값:

```python
selected_trade_id
selected_trade
selected_buy_price
selected_quantity
selected_settlement_amount
```

---

### PHASE 2: 매도 예정값 입력

- [✅] `sell_price` 터미널 입력
- [✅] `sell_quantity` 터미널 입력
- [✅] 입력값을 `Decimal`로 변환
- [✅] 0 이하의 가격 입력 방지
- [✅] 0 이하의 수량 입력 방지
- [✅] 보유수량보다 많은 매도 방지

예시:

```python
sell_price = Decimal(input("매도 예정 가격: "))
sell_quantity = Decimal(input("매도 예정 수량: "))
```

---

### PHASE 3: 개별 매수 거래 기준 매도 계산

- [✅] 선택한 거래의 1개당 실제 매수원가 계산
- [✅] 선택한 거래 기준 매도 원가 계산
- [✅] 매도 거래금액 계산
- [✅] 매도 수수료 계산
- [✅] 매도 정산금액 계산
- [✅] 예상 실현손익 계산
- [✅] 예상 실현수익률 계산
- [✅] 매도 후 남은 수량 계산

계산 흐름:

```text
선택한 거래의 정산금액 ÷ 원래 매수수량
→ 1개당 실제 매수원가

1개당 실제 매수원가 × 매도수량
→ 매도한 물량의 원가

매도가격 × 매도수량
→ 매도 거래금액

매도 거래금액 - 매도 수수료
→ 매도 정산금액

매도 정산금액 - 매도한 물량의 원가
→ 예상 실현손익
```

---

- [✅] 선택한 매수가 출력
