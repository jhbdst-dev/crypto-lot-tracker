# HOME 화면

## 목표

- 홈 화면 데이터 출력
- 출력 확인 후 React 연동

---

## 필요한 데이터

### 전체 자산

- [✅] 총 평가금액
- [✅] 총 평가손익
- [✅] 총 수익률
- [✅] 총 매수금액
- [✅] 보유 코인 수

### 보유 코인

- [✅] 코인명
- [✅] 현재가
- [✅] 보유수량
- [✅] 평균 매수가
- [✅] 평가금액
- [✅] 평가손익
- [✅] 수익률

---

## 개발 순서

1. 데이터 조회
2. 계산
3. 터미널 출력
4. React 연동

---

- [✅] 계좌 정보 조회
  - 보유 코인
  - 보유수량
  - 평균 매수가

- [✅] 실시간 현재가 조회

- [✅] 코인별 자산 계산
  - 총 매수금액
  - 평가금액
  - 평가손익
  - 수익률

- [✅] printer.py 출력

---

- FastAPI 설치
  - pip3 install fastapi uvicorn
  - backend/api.py 생성 및 작성
  - 서버 실행 : uvicorn backend.api:app --reload
