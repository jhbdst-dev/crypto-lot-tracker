## 기존 출력 구조를 변경하는 이유

초기 프로젝트는 터미널에서 결과를 확인하는 CLI 구조였다.

현재 프로젝트는 React UI를 최종 화면으로 사용하므로,
기존 출력 함수들은 프론트엔드 화면과 구조가 맞지 않는다.

기존 출력 코드는 `printer_old.py`에 보관하고,
새로운 `printer.py`는 프론트엔드 화면 단위로 다시 설계한다.

### 2. 전체 자산 요약

모든 보유 코인의 계산 결과를 합산하여 표시한다.

#### 필요한 데이터

- [ ] 총 평가금액
- [ ] 총 평가손익
- [ ] 총 수익률
- [ ] 총 매수금액
- [ ] 보유 코인 수

#### 데이터 의미

```text
총 평가금액
= 모든 보유 코인의 평가금액 합계

총 평가손익
= 총 평가금액 - 총 매수금액

총 수익률
= 총 평가손익 / 총 매수금액 × 100

총 매수금액
= 모든 보유 코인의 총 매수금액 합계

보유 코인 수
= 현재 보유수량이 0보다 큰 코인의 개수
```

#### 구현 작업

- [ ] 코인별 계산 결과를 하나의 저장공간에 모으기
- [ ] 모든 코인의 평가금액 합산
- [ ] 모든 코인의 매수금액 합산
- [ ] 전체 평가손익 계산
- [ ] 전체 수익률 계산
- [ ] 보유 코인 수 계산
- [ ] 전체 자산 요약 터미널 출력

### 3. 보유 코인 목록

현재 보유 중인 코인을 하나씩 표시한다.

#### 공통 데이터

각 코인마다 아래 데이터가 필요하다.

- [ ] 코인
- [ ] 현재가
- [ ] 보유수량
- [ ] 평균 매수가
- [ ] 평가금액
- [ ] 평가손익
- [ ] 수익률

#### 데이터 연결

코인

- market
- 예: KRW-BTC
- 화면 표시: BTC / 비트코인

현재가

- current_price
- WebSocket에서 수신한 실시간 체결가격

보유수량

- total_quantity
- 매수수량에서 매도수량을 차감한 현재 보유수량

평균 매수가

- average_buy_price
- 현재 남아 있는 보유수량의 평균 매수가

평가금액

- current_value
- 현재가 × 보유수량

평가손익

- profit_loss
- 평가금액 - 총 매수금액

수익률

- profit_rate
- 평가손익 / 총 매수금액 × 100
