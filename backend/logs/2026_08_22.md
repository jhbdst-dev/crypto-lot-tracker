## COIN_NAMES 하드코딩 제거

### 문제

- 코인 한글 이름을 `COIN_NAMES` 딕셔너리에 직접 작성하고 있었음.
- 새로운 코인이 추가될 경우 직접 코드를 수정해야 함.

### 개선

- [✅] 업비트 마켓 정보 API 응답 확인
- [✅] `market`, `korean_name` 데이터 확인
- [✅] `get_coin_names()` 함수 생성
- [✅] `market → korean_name` 형태의 딕셔너리 생성
- [✅] 기존 `COIN_NAMES` 전역 변수 제거
- [✅] `get_coin_detail()`에서 `get_coin_names()` 사용
- [✅] `/home` 응답에 `coin_name` 추가
- [✅] `HomePage.tsx`에 `coin_name` 표시
- [✅] BTC / ETH / XRP 정상 출력 확인

### 변경된 데이터 흐름

기존:
`COIN_NAMES 하드코딩 → API 응답`

변경:
`업비트 마켓 API → get_coin_names() → get_home() / get_coin_detail() → React`

### 배운 점

기능을 추가하기 전에 먼저 실제 데이터가 들어오는지 확인하고,
데이터의 출발점부터 백엔드 응답과 프론트 화면까지 흐름을 따라가며
수정해야 할 위치를 찾는 방식으로 작업했다.
