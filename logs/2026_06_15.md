## 현재 평가금액

### 왜 필요한가

현재 보유한 코인이 지금 얼마의 가치인지 확인하기 위해 필요하다.

### 사용한 데이터

- total_quantity (총 보유수량)
- current_price (현재가)

### 계산식

현재 평가금액 = 총 보유수량 × 현재가

current_value = total_quantity \* current_price

### 데이터 이동

total_quantity
current_price
↓
current_value 계산
↓
return
↓
main.py 출력

### 다음 단계

current_value와 total_buy_amount를 이용해서 평가손익을 계산한다.

## 평가손익

### 왜 필요한가

현재 자산이 이익인지 손해인지 확인하기 위해 필요하다.

### 사용한 데이터

- current_value
- total_buy_amount

### 계산식

평가손익 = 현재 평가금액 - 총 매수금액

profit_loss = current_value - total_buy_amount

### 데이터 이동

current_value, total_buy_amount
↓
profit_loss
↓
return
↓
main.py 출력

### 다음 단계

profit_loss를 이용해 수익률을 계산한다.

## 수익률 계산

### 왜 필요한가

현재 투자금 대비 얼마나 이익 또는 손해가 발생했는지
백분율(%)로 확인하기 위해 필요하다.

### 사용한 데이터

- profit_loss (평가손익)
- total_buy_amount (총 매수금액)

### 계산식

수익률 = 평가손익 ÷ 총 매수금액 × 100

profit_rate = (profit_loss / total_buy_amount) \* 100

### 데이터 이동

profit_loss
total_buy_amount
↓
profit_rate 계산
↓
return
↓
main.py 출력
