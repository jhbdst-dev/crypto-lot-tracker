## 계산 기준

### 매도 거래금액

sell_trade_amount = sell_price \* sell_quantity

### 매도 수수료

sell_fee_amount = sell_trade_amount \* fee_rate

### 매도 정산금액

sell_settlement_amount = sell_trade_amount - sell_fee_amount

매도는 수수료를 제외하고 실제 입금되므로 수수료를 뺀다.

### 매도한 원가

sold_buy_amount = average_buy_price \* sell_quantity

처음에는 평균 매수가 기준으로 매도한 원가를 계산한다.

### 실현손익

realized_profit_loss = sell_settlement_amount - sold_buy_amount

### 남은 보유수량

remaining_quantity = total_quantity - sell_quantity

### 남은 총 매수금액

remaining_buy_amount = total_buy_amount - sold_buy_amount

### 남은 평균 매수가

remaining_average_buy_price = remaining_buy_amount / remaining_quantity

## PHASE2 흐름 정리

### 1. 매도 수량(sell_quantity), 매도 가격(sell_price) 추가

- sell_quantity: 사용자가 판매하려는 코인 수량
- sell_price: 사용자가 판매한 가격

main.py에 매도 수량, 매도 가격 변수 작성.

### 2. main.py의 매도수량, 매도가격 -> calculator.py의 calculate_sell() 함수로 전달

- total_quantity : PHASE1에서 계산된 총 보유수량
- sell_quantity : 사용자가 판매하려는 코인 수량
- sell_price : 사용자가 판매한 가격
- calculate_sell() 호출
- total_quantity, sell_quantity, sell_price를 calculate_sell() 함수로 전달

### 3. calculator.py - calculate_sell()

- def calculate_sell() : 매도 계산 함수 선언
- total_quantity, sell_quantity, sell_price를 입력받음
- 함수 안에서 remaining_quantity 계산

- remaining_quantity = total_quantity - sell_quantity
- 남은 수량 = 총 수량 - 매도 수량

- remaining_quantity : 함수가 계산해서 돌려준 결과를 저장하는 변수
- remaining_quantity : 매도 후 남은 수량

- 계산 결과 remaining_quantity를 return
