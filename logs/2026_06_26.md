## PHASE 4: Upbit 현재가 연동 준비

### 작업 이유

현재가는 계속 변하는 데이터이므로 직접 입력하지 않고 업비트에서 실시간으로 받아온다.

REST API는 필요할 때 조회하는 방식이고,

WebSocket은 연결을 유지하며 실시간 데이터를 받기 위해 사용한다.

### 작업 파일

- `upbit_ws.py`
- `upbit_api.py`
- `main.py`

### 역할 분리

- `upbit_ws.py`
  - WebSocket 전용
  - 실시간 현재가 수신

- `upbit_api.py`
  - REST API 전용
  - 보유자산 조회
  - 체결내역 조회
  - 주문내역 조회

- `main.py`
  - 현재가를 받아 계산 함수에 전달
  - 전체 실행 흐름 조립

### 구현 흐름

- WebSocket 라이브러리 설치
  - pip3 install websocket-client
  - Python에서 WebSocket 기능을 사용하기 위해 설치

- WebSocket 라이브러리 import
  - import websocket
  - WebSocket 연결 객체를 생성하기 위한 라이브러리 불러오기

- WebSocket 연결 객체 생성
  - `websocket-client` 라이브러리를 이용하여 Python 내부에 연결 객체 생성
  - 생성된 객체를 `ws` 변수에 저장
  - 이 객체는 업비트 서버와의 연결을 관리한다.

- 업비트 서버 연결
  - connect()
  - 업비트 WebSocket 서버와 연결

- 구독 요청(send)
  - Python이 업비트에게 필요한 데이터를 요청
  - 예) XRP 현재가, BTC 현재가, ETH 현재가

- 현재가 수신(recv)
  - WebSocket 연결을 통해 업비트가 JSON 데이터를 계속 전송
  - Python은 recv()로 데이터를 수신

- JSON 데이터 분석
- 수신한 JSON에서
  - 현재가
  - 코인명
  - 거래시간
- 등 필요한 데이터 추출

- current_price 저장
  - 현재가를 current_price 변수에 저장

- 계산 함수 전달
  - 실시간 현재가로 평가금액과 손익 계산

- 완료 기준
  - WebSocket 연결 성공
  - XRP 현재가 수신 성공
  - current_price 저장
  - calculate_asset() 연결
  - 평가금액 / 손익 실시간 계산
