## PHASE 4: Upbit 현재가 연동 준비

### 작업 이유

현재가는 직접 입력하는 값이 아니라 시장에서 계속 변하는 값이다.  
그래서 업비트에서 현재가를 받아와야 한다.

현재가처럼 계속 변하는 데이터는 WebSocket으로 받고,  
보유자산 / 체결내역 / 주문내역처럼 필요할 때 조회하는 데이터는 REST API로 가져온다.

### 작업 파일

- `upbit_ws.py`
- `upbit_api.py`
- `main.py`

### 역할 분리

- `upbit_ws.py`
  - WebSocket 전용
  - 실시간 현재가 수신

- `upbit_api.py`
  - REST API 전용
  - 보유자산 조회
  - 체결내역 조회
  - 주문내역 조회

- `main.py`
  - 현재가를 받아 계산 함수에 전달
  - 전체 실행 흐름 조립

### 작업 내용

- [ ] `upbit_ws.py` 생성
- [ ] 업비트 WebSocket으로 XRP 현재가 실시간 수신 테스트
- [ ] 받은 현재가를 `current_price` 변수로 사용
- [ ] `calculate_asset(rows, current_price, fee_rate)`에 연결
- [ ] 현재가가 바뀔 때 평가금액 / 평가손익 / 수익률도 바뀌는지 확인
