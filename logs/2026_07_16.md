  - BTC 거래는 BTC끼리
  - ETH 거래는 ETH끼리
  - XRP 거래는 XRP끼리

- [x] 보유 코인 기준 현재가 자동 연결
  - 업비트 계좌 API에서 market 목록 생성

  - 새로운 코인을 사도 코드 수정 없이 자동 반영

- [x] 현재 보유 중인 코인만 출력
  - 업비트 계좌의 현재 보유자산 기준

  - 매도된 수량을 차감한 뒤 남은 수량만 표시

## 출력 구조

### 1. 전체 자산 요약

- 총 매수금액
- 총 평가금액
- 총 평가손익
- 총 수익률

### 2. 코인별 보유 자산

- 보유수량
- 평균매수가
- 현재가
- 총 매수금액
- 평가금액
- 평가손익
- 수익률

### 3. 개별 코인 매수 거래

- 거래 날짜
- 매수수량
- 매수가
- 투자금액
- 현재 평가금액
- 예상 손익
- 수익률

### 4. 매도 출력

- 매도수량
- 매도가
- 매도금액
- 수수료
- 실수령액
- 실현손익
- 남은 보유수량
- 남은 평균매수가
