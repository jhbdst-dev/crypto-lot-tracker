## 파이썬 가상환경 셋팅

### 프로젝트 폴더 이동

- cd crypto-lot-tracker

### 가상환경 생성

- python3 -m venv .venv

❌ python3 -m venv .venv 실행 중에 실패해서 .venv 폴더가 제대로 만들어지지 않았어. ❌

명령어로 확인

- ls -a

.venv가 없거나, 있어도 깨진 상태일 가능성이 있어.

있다면 지우고 다시 만들자.

- rm -rf .venv

pip 없이 가상환경을 먼저 생성

- python3 -m venv .venv --without-pip

활성화:

- source .venv/bin/activate

pip 설치 확인:

- python -m ensurepip --upgrade

패키지 설치:

- python -m pip install psycopg2-binary
